Bororo Language Corpus

CorBo is a documentary corpus of Bororo (Boe), spoken in Mato Grosso, Brazil. It brings together oral narratives, archival and fieldwork texts, songs, biblical translations and dictionary materials, aligned with Portuguese translations where available and partly annotated in CoNLL-U following Universal Dependencies.

The site interface for reading and search tools is in Portuguese. Bororo texts, translations, data files and documentation are usable without Portuguese; the pages below explain what each part contains.

About the project

CorBo keeps the documentary source separate from editorial revision, collation and linguistic annotation, so that corrections never silently overwrite the source. Read more in About and How to use the site.

The project is developed by Fabrício Ferraz Gerardi within the Boe eno moto initiative, in partnership with Mariel Kujibo Ekureu, Fernando Kudoro and the Salesian Mission, with the communities of Meruri, Tadarimana and Córrego Grande.
