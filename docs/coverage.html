Interpretação

A cobertura lexical corresponde a LEMMA + UPOS; a cobertura morfológica usa FEATS; a sintática requer HEAD + DEPREL. Campos _ são tratados como não anotados, exceto HEAD=0/DEPREL=root, que constituem análise sintática válida.

O painel é calculado dos JSONs gerados a partir do CoNLL-U atual. Quando um novo arquivo anotado for incorporado e os índices forem reconstruídos, estes números se atualizarão automaticamente.
