# Etnobotânica

Coleção de nomes e descrições etnobotânicas em Bororo incorporada ao CorBo.

O arquivo `etnobotanica.tsv` preserva somente as duas colunas selecionadas para o corpus: `name` (nome em Bororo) e `description` (descrição em Bororo), além do identificador editorial `id`.

Os dados derivados para o site são gerados automaticamente por `scripts/build_corpus_indexes.py`.
