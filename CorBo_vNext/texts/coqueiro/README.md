# Coqueiro

Corpus text extracted from `Coqueiro_tudo_borpor.pdf`.

This directory keeps two derived views of the same material with stable `BOR-CORBO-COQ-*` IDs:

- `coqueiro_parallel.tsv`: reviewed Bororo with Portuguese translation/interpretation for structurally aligned units.
- `coqueiro_bororo.tsv`: reviewed Bororo-only view for corpus, search and computational use.

## Review status

The current dataset contains 653 structurally aligned units. Orthographic review has been completed manually for all seven batches (001–007), totaling 653 reviewed units.

A further set of 218 source units remains outside the parallel dataset because their Bororo–Portuguese structural alignment requires separate review. They must not be incorporated automatically as aligned pairs.

The source transcription is not overwritten by these derived files. The corpus workflow distinguishes source transcription, reviewed orthography, and later optional normalization. No UD or morphosyntactic annotation belongs to this CorBo layer.
