# Coqueiro

Corpus text extracted from `Coqueiro_tudo_borpor.pdf`.

This directory keeps two derived views of the same aligned material:

- `coqueiro_parallel.tsv`: Bororo with Portuguese translation/interpretation where available.
- `coqueiro_bororo.tsv`: Bororo-only view for corpus use.

The `id` values are preserved across both files.

## Review status

The current dataset contains 653 structurally aligned units. Orthographic review has been completed manually for batches 001–005 and 007 (553 units). Batch 006 (100 units) currently contains the automatically pre-corrected form and is explicitly marked `pending_manual_review`; it must not yet be treated as manually verified.

A further set of 218 source units remains outside these files because their structural alignment requires separate review.

The source transcription is not overwritten by these derived files. The corpus workflow distinguishes source transcription from reviewed orthography and later optional normalization.
